# TaskScheduler & Data Pipeline (C++)

Шаблонный планировщик задач на C++, основанный на графе зависимостей (**DAG — Directed Acyclic Graph**) с поддержкой мемоизации результатов, ленивых вычислений и прикладных задач (агрегация геоданных, погоды и интересных мест).

---

## 🎯 Основные возможности

### 1. Планировщик задач (`TaskScheduler`)
- **Граф зависимостей**: задачи могут зависеть от результатов выполнения других задач. Планировщик автоматически строит корректный порядок вычисления.
- **Мемоизация / Кеширование**: результаты вычисленных подзадач кешируются, предотвращая повторные вычисления одной и той же ветки графа.
- **Шаблонный дизайн**: возможность связывать функции с произвольными типами аргументов и возвращаемых значений.
- **Безопасность типов**: валидация типов на этапе компиляции при передаче зависимостей между задачами.

### 2. Прикладной конвейер (Geo & Weather Pipeline)
- **`getLocation`** — получение координат и метаданных локации.
- **`getWether`** — интеграция с API прогноза погоды.
- **`getPlaces`** — получение информации о достопримечательностях и интересных местах по координатам.
- Обработка табличных данных (`students.csv`, `groups.csv`).

## 💡 Пример использования TaskScheduler

```cpp
#include "task_scheduler.h"
#include <iostream>

int main() {
    TaskScheduler scheduler;

    // Регистрация независимых и зависимых задач
    auto taskA = scheduler.add([]() { return 10; });
    auto taskB = scheduler.add([]() { return 20; });
    
    // taskC зависит от результатов выполнения taskA и taskB
    auto taskC = scheduler.add([](int a, int b) { 
        return a + b; 
    }, taskA, taskB);

    // Вычисление выполняется с учетом зависимостей и кеширования
    std::cout << "Result: " << scheduler.getResult<int>(taskC) << "\n"; // 30

    return 0;
}
```
